# Курсовая работа
# Описание:
В работе выполнена имитация работы пользователя с банковскими операциями с опорой на файл типа xlsx с транзакциями 
представленными в виде дата фрейма. Реализовано приветствие пользователя в зависимости от времени суток обращения 
пользователя. Была реализована согласно задания вэб страница "Главная". Из сервисов "Выгодные категории 
повышенного кешбэка". Из отчетов реализован "Траты по категории".

# Установка:
1. Клонируйте репозиторий ''' git clone '''.
2. Установите зависимости: ''' pip install -r requirements.txt '''
3. Запуск из модуля main.py


# Тестирование:
Выполнено частичное тестирование модулем pytest, на боллее чем 75% из условия курсовой работы, так же выполнено 
логирование всех функций проекта с возможностью отслеживания в лог файлах работы функций их переменных и дата фреймов 
используемых и образуемых во время работы функций.
